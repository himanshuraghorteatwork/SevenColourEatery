# Seven Colours Eatery

Premium React website for Chef Nolu Dube-Cele’s restaurant at Battery Park, V&A Waterfront, Cape Town.

## Run

```bash
npm install
npm run dev
```

## Admin

Kitchen notes at `/admin` stay locked until you add `VITE_ADMIN_PASSWORD` to a local `.env` file. Data is stored in this browser only. Supabase is not connected.

Menu prices are placeholders. Confirm live tariffs with the restaurant before treating them as official.
